What this view shows

The OVF is optical, so it can only show a bright-frame guide, and parallax shifts it at close range. The RAF view assumes the sensor data is kept in full and the crop is stored as a reversible setting. That is how Fujifilm's GFX files appear to behave, and it has not been confirmed for the X100V.
