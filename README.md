# X100V 65:24 research

Research tools and tests for an experimental 65:24 crop on Fujifilm X100V
firmware 3.01. This repository has a new public history. It contains source
code and synthetic tests only. It contains no Fujifilm firmware images,
camera files, settings backups, private test logs, or ready-to-use SD boot files.

## Current evidence

- A temporary SD boot experiment using the existing `L 16:9` setting produced
  centered 65:24 JPEGs. A later experiment produced RAF files whose crop
  presentation was recognized as 65:24 by Lightroom. These observations come
  from physical tests; the files and their identifying metadata are private.
- Separate experiments changed the live-view crop on LCD and EVF.
- The OVF has two distinct controls. Earlier layout edits narrowed the corner
  marks while the solid frame stayed 16:9. A later height-factor edit changed
  the solid bright frame to 65:24 on the camera; the owner observed it shift
  with focus distance and align with the corner marks. See the
  [OVF research note](docs/ovf-bright-frame-20261112.md).
- The research tools include exact-byte checks, geometry calculations,
  update-container inspection, and bounded ARM probes. Their tests do not
  establish that any candidate is safe to flash.

No internal firmware flash has been performed. There is no public release or
camera-ready patch. Do not flash code generated by these tools. Fujifilm owns
its firmware; this repository grants no rights to redistribute it.

## Running focused source tests

Python 3.13 or newer is recommended. The synthetic tests use the dependencies
in `requirements-dev.txt`:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q \
  tests/test_x100v_ovf_window_6524.py \
  tests/test_x100v_focus_grid_6524.py \
  tests/test_x100v_preview_frame_6524.py \
  tests/test_x100v_xpan_simulator.py
```

The broader historical suite includes tests that need locally supplied
official update files, Unicorn, Capstone, or other optional dependencies. It
has not been run as a complete gate in this public snapshot. A passing source
test does not prove camera behavior.

The `xpan-crop/` application is a separate post-capture crop helper from the
earlier `xpan-crop` source snapshot at revision `cd3ac20`. It does not emulate
camera firmware.

## Research boundaries

The code is published for study and review. Before a camera-ready release,
the remaining work includes measuring OVF alignment across focus distances,
validating JPEG and RAF
output on held-out scenes, and establishing updater acceptance and stock
recovery. All firmware inputs must be provided by the user from an authorized
source.
